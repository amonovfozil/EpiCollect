# Collector app surface

Scope: whole collector mobile app (login, projects, project detail, form fill, submission detail, drafts, profile). Mode: Operate. Platform: adaptive, Cupertino on both OSes per explicit user brief. Code-led.

## Direction contract
seed: 700381720e00cf2ca551b14131eb9b6a (index 6)

THESIS: A calm field tool where every project is recognised by an app-icon style mark (one deep hue + topic icon chosen from the project's own words). User rejected the multicolour atlas band on 2026-11-24 as noisy and slow; it is retired.

OWN-WORLD: iOS system grouped backgrounds, SF type, CupertinoIcons only. One indigo tint for interaction. Project marks in six deep tones; project cover is a soft wash of that hue with the mark and a large cropped icon. Inset grouped sections.

STORY: Collector opens app, spots the project by its mark, taps, opens form, watches the progress line fill and turn green, submits, sees status.

FIRST VIEWPORT: Large-title "Loyihalar", greeting, search, project rows with mark, name, status and role.

SIGNATURE: Mark flies from list to project cover (Hero); progress line turns green when all answers are given.

RISK: Keyword-based icons can mislabel a topic; fallback icons stay neutral.
